# Вопросы владельцу: семантика переходов UI-моделей (задача 2.5) + общие вопросы (Q18 — задача 3.2)

R4: в мете `click_leads_to: null` для всех 165 кропов — семантику переходов
мета не знает. Разметка 2.5 заполнила только переходы, прямо подтверждённые
парами скриншотов «до/после» (см. отчёт 2.5). Всё ниже — закрывается только
знанием игры + досъёмкой. Ответы переносятся напрямую в `ui_model/*.yaml`
(шаблон ответа указан у каждого вопроса); закрытый вопрос убирает запись из
`ui_model/KNOWN_GAPS.yaml` правкой модели.

Формат ответа на каждый вопрос: (а) что происходит, (б) наблюдаемый признак
цели (что должно появиться/исчезнуть на экране), (в) что делать при сбое.
