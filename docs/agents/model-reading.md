# Слой модели: грамматики и чтение OCR (задачи 4.4, 4.5)

> Детальный справочник по слою `l2core/model/`, вынесенный из AGENTS.md
> (прогрессивная загрузка: AGENTS.md — ядро, этот файл — детали по слою).
> Правится вместе с кодом: обновление затронутых заметок `docs/agents/` —
> часть DoD ломающих задач (см. «Правила изменений» в AGENTS.md).

## Грамматики OCR-регионов (4.4, grammars.py)

Чистые функции разбора значений по грамматике (`digits`, `price` с
разделителями `,`/`.`, суффиксами `к`/`кк` и составной игровой записью
«x млрд y млн z тыс d аден» (Q22: `_parse_composite`, сумма компонентов,
масштабы строго по убыванию, голое число в середине — несовпадение;
слова-масштабы — ключи suffixes длиной ≥ 3, «аден» — units), `text`),
валидация по диапазону (дефолт price 1..2^63-1, digits 0..2^63-1;
опциональные `min`/`max`/`units` в грамматике — FORMAT.md) и механизм
перечитывания при несовпадении: `read_region(ocr, frame, rect, grammar)`
через контракт OcrClient — одно перечитывание с увеличением региона, при
повторе — статус `invalid`, `confidence=0.0` (сигнал «не сошлось»).

## Слой чтения (4.5, reading.py)

`read_confident` — цикл до `reread_count` перечитываний с увеличением
региона (внешняя попытка k стартует с региона +k·pad от исходного;
внутренняя перечитка read_region — +pad при несовпадении грамматики,
двойного расширения нет) до порога `confidence_threshold` из конфига,
исчерпание → `OcrReadError` с диагностикой (region_id, threshold,
attempts: rect/text/confidence/status); `read_stable` — стабилизация
поля ввода от мигающей каретки: чтение кадров от источника
(`frame_source()`, совместимо с Screen.grab) до двух подряд одинаковых
текстов, лимит `max_frames`, исчерпание → `OcrReadError`; стабильный
текст совпавший с regex-паттерном `placeholder` региона (опциональное
поле ocr_regions, FORMAT.md) или пустой → status `placeholder`,
value=None (плейсхолдер ≠ введённый текст).
