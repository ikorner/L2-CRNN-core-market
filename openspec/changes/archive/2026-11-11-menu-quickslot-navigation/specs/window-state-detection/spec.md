# Spec Delta: window-state-detection

## ADDED Requirements

### Requirement: Детектор якоря окна торговли поддерживает многоопорный якорь
Детектор SHALL хранить на окно кортеж опор `anchor_templates: window -> [опоры]` вместо единственной опоры; `find_anchor` SHALL перебирать опоры template matching'ом по порогу окна и возвращать Anchor по первой сошедшейся опоре. Для market поведение не меняется (опора одна — существующий заголовок). Опорами открытых окон лавок становятся импортированные кропы заголовков «Торговая лавка» (досъёмка open-окон без перекрытий — развязка KNOWN_GAPS п. 6).

#### Scenario: Якорь open-окна лавки находится по заголовку
- **WHEN** `find_anchor` вызывается на кадре чистого open-окна shop_sell (досъёмка)
- **THEN** якорь находится по одной из опор кортежа, `ANCHOR_ABSENT_OPEN` больше не ожидается на таком кадре

#### Scenario: Первая сошедшаяся опора даёт Anchor
- **WHEN** у окна несколько опор и первая по порядку не находится, а вторая — находится выше порога
- **THEN** возвращается Anchor по второй опоре

#### Scenario: Поведение market не изменилось
- **WHEN** `find_anchor` вызывается для market на существующем сырье
- **THEN** результаты совпадают с одноопорным поведением (guard-тест на эталонных кадрах)
